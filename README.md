# AdMob eCPM 分析网页（V1）

一个纯前端网页工具，用于解析 AdMob 后台导出的按国家、按广告单元 Excel/CSV 报表。

## 你的问题：没有 python3 能不能用？

可以。**这个版本不依赖本地 python3 / node / 后端服务**。

### 使用方式 A（零环境，推荐）

1. 下载项目文件到本地。
2. 直接双击 `index.html`（或拖入浏览器）。
3. 点击页面里的 **「选择 Excel 文件」** 上传报表。

> 说明：Excel 解析库通过公网 CDN 加载，所以需要能访问外网。

### 使用方式 B（随时可调用，不依赖你本机环境）

把整个目录部署到任意静态托管：
- GitHub Pages
- Vercel
- Netlify
- Cloudflare Pages

部署后你会得到一个固定 URL，之后随时打开即可使用。

## 功能

- 上传 `.xlsx / .xls / .csv` 文件。
- 自动识别国家列、广告单元列、eCPM 列。
- 广告单元按 `产品名_广告位_广告类型_出价高低类型` 自动拆分。
- 按 eCPM 降序展示在线表格。
- 支持国家、广告位筛选。
- 支持导出当前视图 CSV。
- 支持导出结构化 JSON（国家 -> 广告位 -> 广告单元列表）。

## 常见问题

- 页面显示 Not Found：通常是你打开了错误 URL 或旧预览缓存；直接打开本地 `index.html` 即可。
- 上传按钮不可用：说明 Excel 解析库还未加载完成，等待状态文案变为“已加载”。
