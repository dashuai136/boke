# AdMob eCPM 分析网页（V1）

一个纯前端网页工具，用于解析 AdMob 后台导出的按国家、按广告单元 Excel/CSV 报表。

## 已修复：卡在“初始化 Excel 解析库”

当外网限制导致 CDN 无法访问时，旧版本会一直不可用。现在已改为：

- 页面**不再阻塞上传入口**；
- 初始化失败时自动降级为 **CSV 可用模式**；
- 页面显示清晰状态，并提供“重试加载 Excel 解析库”按钮。

## 使用方式

### 方式 A：直接本地打开（无需 Python/Node）

1. 下载项目文件。
2. 双击 `index.html`（或拖入浏览器）。
3. 上传文件：
   - 若状态显示“Excel 解析库已加载”，可上传 `.xlsx/.xls/.csv`；
   - 若状态显示“加载失败”，请先把报表另存为 `.csv` 再上传。

### 方式 B：随时可调用（固定 URL）

部署到任意静态托管：GitHub Pages / Vercel / Netlify / Cloudflare Pages。

## 功能

- 上传 `.xlsx / .xls / .csv` 文件。
- 自动识别国家列、广告单元列、eCPM 列。
- 广告单元按 `产品名_广告位_广告类型_出价高低类型` 自动拆分。
- 按 eCPM 降序展示在线表格。
- 支持国家、广告位筛选。
- 支持导出当前视图 CSV。
- 支持导出结构化 JSON（国家 -> 广告位 -> 广告单元列表）。
