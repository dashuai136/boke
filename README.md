# AdMob eCPM 分析网页（V1）

一个纯前端网页工具，用于解析 AdMob 后台导出的按国家、按广告单元的 Excel 报表。

## 功能

- 上传 `.xlsx / .xls / .csv` 文件（含明确上传入口）。
- 在线表格展示结果，按 eCPM 从高到低排序。
- 自动识别国家列、广告单元列、eCPM 列。
- 基于广告单元命名规范 `产品名_广告位_广告类型_出价高低类型` 自动拆分字段。
- 支持按国家、按广告位筛选。
- 支持导出当前视图为 CSV。
- 支持导出结构化 JSON（国家 -> 广告位 -> 按 eCPM 排序的广告单元列表）。
- 内置多 CDN 回退，避免 Excel 解析库单点地址失效导致页面不可用。

## 首次使用（你要访问的页面入口）

在项目目录执行：

```bash
python3 -m http.server 8000
```

然后在浏览器访问：

- `http://127.0.0.1:8000/`
- 或 `http://127.0.0.1:8000/index.html`

> 上传入口就是页面里的「选择 Excel 文件」按钮。

## 如果你看到 Not Found（常见原因）

1. **服务没有在项目根目录启动**：请先 `cd /workspace/boke` 再启动服务。
2. **访问了错误端口/路径**：请确认是 `8000` 端口，并优先访问 `/` 或 `/index.html`。
3. **预览图是旧缓存**：刷新预览，或重新打开一次页面链接。
